# Archive model attribution

Generic cassette geometry adapted from [LBEILC / RhineLabUI](https://github.com/LBEILC/RhineLabUI), `public/assets/archive-cassette.glb`, downloaded 2026-11-05.

Copyright (c) 2026 LBEILC. MIT license in LICENSE.txt.

PHRNONO modifications: removed the entire Carbon_Ink, Internal_Ceramic and Moulded_Lettering geometry groups containing the original company/database/edge lettering; pruned unused mesh data; supplied independent Cia content and recolored materials at runtime. No original logo, character, lore, audio or printed texture is included. Original geometry has no embedded image textures.

The borrowed model is credited here as a visual presentation dependency; it is not presented as PHRNONO's original 3D portfolio work.

The scene also adapts the reference's framing, settled column shoulder formula and frosted height tint from its MIT-licensed scene/motion/appearance code. Interaction state, capability copy, finite rendering lifecycle and responsive reading layout are integrated for this portfolio. Mobile uses opaque background shells and omits instanced fasteners to reduce rendering cost.
